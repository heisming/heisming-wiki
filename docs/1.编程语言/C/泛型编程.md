# 泛型编程

> 可以编写完全一般化并可重复使用的算法，其效率与针对某特定数据类型而设计的算法相同。

## 通过无类型指针 void*(T)
>🎁`void *`类型表示未确定类型的指针。`C、C++`规定 `void *`类型可以通过**类型转换强制转**换为任何其它类型的指针。
```c
void swap(int *i1, int *i2)
{
	int temp;
	temp = *i1;
	*i1 = *i2;
	*i2 = temp;
}
```
当想交换两个 `char` 类型时，还得重写一个参数类型为 `char` 的函数，是不是能用无类型的指针来作为参数呢？

如下改动：
```c
// 不能将 * 用在无类型指针上，因为系统没有此地址指向对象大小的信息
void swap(void *v1, void *v2) // ❌调用此函数传进的参数是什么类型的？
{
	void temp; // ❌变量是不能声明为 void 无类型的
	temp = *v1;
	*v1 = *v2;
	*v2 = temp;
}
```
这段代码是错误的，在编译阶段，编译器无法得知传入此函数参数的类型的。

改动如下：
```c
#include <stdio.h>
#include <string.h>

void swap(void *v1, void *v2, int size)
{
	char buffer[size]; // 注意此处gcc编译器是允许这样声明的
	memcpy(buffer, v1, size);
	memcpy(v1, v2, size);
	memcpy(v2, buffer, size);
}

int main()
{
	int x = 25, y = 2;
	swap(&x, &y, sizeof(int));
	printf("x = %d, y = %d", x, y);
   	return 0;
}
```
编译并运行
```bash
x = 2, y = 25
```

**案例2**：在数组 array 中查找 key元素，找到后返回它的索引，找不到返回 -1。
-
```c
int lsearch(int key, int arr[], int size)
{
	for(int i = 0; i < size; ++i)
	{
		if (arr[i] == key)
		{
			return i;
		}
	}
	return -1;
}
```
实现泛型的函数
```c
void *lsearch(void *key, void *base, int n, int elemSize)
{
	for(int i = 0; i < n; ++i)
	{
		void *elemAddr = (char *)base + i * elemSize;
		if(memcmp(key, elemAddr, elemSize) == 0)
		{
			return elemAddr;
		}
	}
	return NULL;
}
```
将数组的首地址强制转换为指向 `char` 类型的指针，是利用 `char` 类型大小为1字节的特性，使 `elemAddr` 指向此"泛型"数组的第 `i - 1` 个元素的首地址。

不知道传入的是什么类型的数据，系统无法确定此数组一个元素有多长，跳向下个元素需要多少字节，所以强制转换为指向 `char` 的指针，再加上参数传入的元素大小信息`elemSize`和累加数`i`的乘积，即**偏移地址**，即可得此数组第 `i - 1` 个元素的首地址。

这样使无论传入的参数是指向什么类型的指针，都可以得到指向正确元素的指针，实现***泛型编程***。

```c
#include <stdio.h>
#include <string.h>

int main()
{
	int x = 25, y = 2;
	int arr[] = {2, 4, 6, 25};
	
	printf("lsearch = %p", lsearch(&x, arr, sizeof(arr), sizeof(int)));
   	return 0;
}
```
编译并执行
```bash
lsearch = 0x7ffd91d9fa4c
```
`memcmp`: 此函数在数组 `base` 中查找 `key` 元素，找到则返回它的地址信息，找不到则返回 `NULL`。可以使用函数指针，实现其行为的泛型：
```c
#include <stdio.h>

void *lsearch(void *key, void *base, int n, int elemSize, int (*cmpfn)(void*, void*, int))
{
	for(int i = 0; i < n; ++i)
	{
		void *elemAddr = (char *)base + i * elemSize;
		if(cmpfn(key, elemAddr, elemSize) == 0)
		{
			return elemAddr;
		}
	}
	return NULL;
}

int intCmp(void *elem1, void *elem2, int size)
{
	int *ip1 = elem1;
	int *ip2 = elem2;
	return *ip1 - *ip2;
}

int main()
{
	int arr[] = {2, 4, 6, 25, 3};
	int size = sizeof(arr) / sizeof(arr[0]), num = 3;	
	int *found = lsearch(&num, arr, size, sizeof(int), intCmp);
	if (found == NULL) {
		printf("No Found");
	}
	else {
		printf("Found it");
	}
   	return 0;
}
```
编译并执行
```bash
Found it
```

- `void*` + `char[]`实现泛型编程

> C 语言也可以实现一定的泛型编程，但这样是不安全的，系统对其只有有限的检查。在编程时一定要多加细心。
