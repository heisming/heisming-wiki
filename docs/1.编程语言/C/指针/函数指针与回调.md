# 函数指针
> 指向函数的指针变量。

```c
// 声明一个指向同样参数、返回值的函数指针类型
typedef int (*fun_p)(int, int);
```
像一般函数一样，用于调用函数、传递参数。

```c
#include <stdio.h>

int max(int x, int y)
{
	return x > y ? x : y;
}

int main(void)
{
	// p 是函数指针
	int (*p)(int, int) = &max; // & 可以省略
	int a, b, c, d;
	
	printf("请输入三个数字:");
	scanf("%d %d %d", &a, &b, &c);
	
	// 与直接调用函数等价，d = max(max(a, b), c)
	d = p(p(a, b), c);
	printf("最大的数字是 : %d\n", d);
	
   	return 0;
}
```
编译并执行
```bash
请输入三个数字: 1 2 3
最大的数字是: 3
```

# 回调函数
> **回调函数**就是一个通过函数指针调用的函数。

函数指针（地址）变量可以作为参数传递给另一个函数; 

**不带参数的函数指针**
- `size_t`: 为了保证 `arraySize`有足够大的数据来存储数组(不涉及负值范围)， 数值范围一般是要大于`int`和`unsigned`。
```c
#include <stdio.h>
#include <stdlib.h>

void populate_array(int *array, size_t arraySize, int (*getNextValue)(void))
{
	for (size_t i = 0; i < arraySize; i++)
		array[i] = getNextValue();
}

// 获取随机值
int getNextRandomValue(void)
{
	return rand();
}

int main(void)
{
	int arr[10];
	// getNextRandowValue不能加(),相当于执行函数返回int型数值,而不是函数指针
	populate_array(arr, 10, getNextRandomValue);
	for(int i = 0; i < 10; i++)
	{
		printf("%d ", arr[i]);
	}
	printf("\n");
		
   	return 0;
}
```
编译并执行
```bash
1804289383 846930886 1681692777 1714636915 1957747793 424238335 719885386 1649760492 596516649 1189641421 
```

**带参数的函数指针**
```c
#include <stdio.h>

// 回调函数
int add(int a, int b)
{
	return a + b;
}

// sum回调add函数
int sum(int num, int a, int b, int (*add)(int, int))
{
	return num * add(a, b);
}

int main(void)
{
	int (*p)(int, int) = &add; // 函数指针
	
	printf("add = %d\n", add(1, 2));
	printf("add = %d\n", p(3, 4));
	printf("sum = %d\n", sum(5, 6, 7, p)); // 这里的用法叫什么呢？
	printf("sum = %d\n", sum(8, 9, 10, add));

   	return 0;
}
```
编译并执行
```bash
add = 3
add = 7
sum = 65
sum = 152
```

## 为啥不用普通函数？

> 仔细想想回调函数的作用完全可以通过普通函数来达到，其实回调函数最大的意义在于**解耦**，降低了代码之间的耦合度。

![callback](https://www.runoob.com/wp-content/uploads/2019/11/2ecc00017db499f2620d.jpeg)
```c
#include<stdio.h>
#include<softwareLib.h> // 包含Library Function所在读得Software library库的头文件

int Callback() // Callback Function
{
    // TODO
    return 0;
}
int main() // Main program
{
    // TODO
    // Library函数里面需要传递一个函数指针类型的参数：int (*cb)(void)
    Library(Callback); 
    // TODO
    return 0;
}
```
在回调中，主程序把回调函数像参数一样传入库函数。这样一来，只要**改变传进库函数的参数**，就可以实现不同的功能, 并且丝毫不需要修改库函数的实现，这就是解耦。

主函数和回调函数是在同一层的，而库函数在另外一层，如果库函数不可见并修改不了，也就是说不能通过修改库函数让库函数调用普通函数那样实现，那就只能通过传入不同的回调函数了。

举个例子
```c
#include <stdio.h>

// 回调函数A
int callback_A() 
{
	printf("Callback A Run\n");
	return 0;
}

// 回调函数B
int callback_B() 
{
	printf("Callback B Run\n");
	return 0;
}

// 回调函数C
int callback_C() 
{
	printf("Callback C Run\n");
	return 0;
}

// * 这个类似于库函数
int handle(int (*cb)(void)) 
{
	printf("Entering Handle Function.\n");
	cb();
	printf("Leaving Handle Function.\n");
}

int main(void)
{
	printf("Entering Main Function.\n");
	handle(callback_A);
	handle(callback_B);
	handle(callback_C);
	printf("Leaving Main Function.\n");
	
   	return 0;
}
```
> 回调函数其实就是函数指针的一种用法。
