# 指针数组
> - 指针数组是存储了一组指针的数组，其中的每个元素都是指向某种数据类型的指针，每个指针可以指向不同的数据对象。

指针数组通常用于处理多个数据对象，例如字符串数组或其他复杂数据结构的数组。

C语言中的指针和数组名不完全等价，不能将它们混为一谈

```c
#include <stdio.h>

const int MAX = 3;

int main()
{
	int num[] = {10, 100, 1000};
   	int i;
	for(i = 0; i < MAX; i++)
	{
		printf("Value of num[%d] = %d\n", i, num[i]);
	}
   	return 0;
}
```
编译并执行
```bash
Value of num[0] = 10
Value of num[1] = 100
Value of num[2] = 1000
```

想要让数组存储指向 `int` 或 `char` 或其他数据类型的指针。

```c
#include <stdio.h>

const int MAX = 3;

int main()
{
	int num[] = {10, 100, 1000};
    int i, *p[MAX]; // 指向整数的指针数组的声明
	for(i = 0; i < MAX; i++)
	{
		p[i]= &num[i]; /* 赋值为整数的地址 */
	}
	
	for(i = 0; i < MAX; i++)
	{
		printf("Value of num[%d] = %d\n", i, *p[i]);
	}
   	return 0;
}
```
编译并执行
```bash
Value of num[0] = 10
Value of num[1] = 100
Value of num[2] = 1000
```

**指向字符的指针数组来存储一个字符串列表**

```c
#include <stdio.h>

const int MAX = 4;

int main()
{
	const char *names[] = {
		 "Zara Ali",
         "Hina Ali",
         "Nuha Ali",
         "Sara Ali",
	};
	int i;
	for(i = 0; i < MAX; i++)
	{
		printf("Value of names[%d] = %s\n", i, names[i]);
	}
   	return 0;
}
```
编译并执行
```bash
Value of names[0] = Zara Ali
Value of names[1] = Hina Ali
Value of names[2] = Nuha Ali
Value of names[3] = Sara Ali
```
再来一个示例
```c
#include <stdio.h>

int main()
{
	int num1 = 10, num2 = 20, num3 = 30;
	
	// 声明一个整数指针数组，包含三个指针
	int *pArray[3];
	
	// 将指针指向不同的整数变量
	pArray[0] = &num1;
	pArray[1] = &num2;
	pArray[2] = &num3;
		
	// 使用指针数组访问这些整数变量的值
	printf("Value at index 0: %d\n", *pArray[0]);	
	printf("Value at index 1: %d\n", *pArray[1]);
	printf("Value at index 2: %d\n", *pArray[2]);
   	return 0;
}
```
编译并执行
```bash
Value at index 0: 10
Value at index 1: 20
Value at index 2: 30
```

> - **指针(的)`数组`**：表示的是一个由指针变量组成的数组，也就是说其中的元素都是指针变量。
> - **数组(的)`指针`**：表示的是这是个指向数组的指针，那么该指针变量存储的地址就必须是数组的首地址
