# 指针的算术运算
C 指针是一个用数值表示的地址。因此，可以对指针进行四种算术运算：`++`、`--`、`+`、`-`。

- 指针的每一次递增，它其实会指向下一个元素的存储单元。
- 指针的每一次递减，它都会指向前一个元素的存储单元。
- 指针在递增和递减时跳跃的字节数取决于指针所指向变量数据类型长度，比如 int 就是 4 个字节, char 是 1 个字节。

## 递增
> 递增一个指针意味着让指针指向下一个内存位置。

在程序中使用指针代替数组，因为变量指针可以递增，而数组不能递增，数组可以看成一个指针常量。
```c
#include <stdio.h>

const int MAX = 3;

int main()
{
	// 定义一个整数数组
	int num[] = { 10, 100, 1000 };
	// 定义一个整数变量 i 和一个指针 p
	int i, *p;
	
	// 将指针 p 指向数组 num 的起始地址
	p = num;
	// 循环遍历数组
	for (i = 0; i < MAX; i++)
	{
		// 打印当前指针 p 所指向的地址
		printf("存储地址: num[%d] = %p\n", i, p);
		// 打印当前指针 p 所指向地址的值
		printf("存储值: num[%d] = %d\n", i, *p);
		
		// 将指针 p 移动到下一个数组元素的位置
		p++;
	}
	
	return 0;
}
```
编译并执行
```bash
存储地址: num[0] = 0x7ffd9d96e6f4
存储值: num[0] = 10
存储地址: num[1] = 0x7ffd9d96e6f8
存储值: num[1] = 100
存储地址: num[2] = 0x7ffd9d96e6fc
存储值: num[2] = 1000
```

**字符**
```c
#include <stdio.h>

int main()
{
	char str[] = "Hello";
	char *p = str; // 指针指向字符串的第一个字符
	
	printf("start char: %c\n", *p);
	
	p++; // 递增指针，使其指向下一个字符
	printf("p++ char: %c\n", *p);
	
	return 0;
}
```
编译并执行
```bash
start char: H
p++ char: e
```

**结构体**
```c
#include <stdio.h>

struct Point {
	int x;
	int y;
};

int main()
{
	struct Point points[] = { {1, 2}, {3, 4}, {5, 6}};
	struct Point *p = points; // 指针指向结构体数组的第一个元素
	
	printf("start: (%d, %d)\n", p->x, p->y);
	
	p++;// 递增指针，使其指向下一个结构体
	printf("p++: (%d, %d)\n", p->x, p->y);
	
	return 0;
}
```
编译并执行
```bash
start: (1, 2)
p++: (3, 4)
```
p++ 使指针从 points[0] 指向 points[1]。因为 p 是一个 struct Point 类型指针，所以它递增时会移动 sizeof(struct Point) 个字节。

## 递减
> 与递增相反

```c
#include <stdio.h>
 
int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = &arr[4];  // 指针指向数组的最后一个元素
 
    printf("初始值: %d\n", *p);  // 输出 50
 
    p--;  // 递减指针，使其指向前一个整数元素
    printf("递减后值: %d\n", *p);  // 输出 40
 
    p--;  // 再次递减指针
    printf("再次递减后值: %d\n", *p);  // 输出 30
 
    return 0;
}
```
编译并执行
```bash
初始值: 50
递减后值: 40
再次递减后值: 30
```
**字符和结构体与递增相反**

## 比较
> 指针比较主要用于确定两个指针是否指向相同的内存位置或确定一个指针是否位于另一个指针之前或之后。

用关系运算符进行比较，如`==`、`!=`、`<`、`>`、`<=` 和 `>=`。

**相等比较**
```c
#include <stdio.h>

int main()
{
	int a = 5;
	int b = 10;
	int *p1 = &a;
	int *p2 = &a;
	int *p3 = &b;
	
	if (p1 == p2)
	{
		printf("p1 和 p2 指向相同的内存地址\n");
	}
	else
	{
		printf("p1 和 p2 指向不同的内存地址\n");
	}
	
	if (p1 != p3)
	{
		printf("p1 和 p3 指向不同的内存地址\n");
	}
	else
	{
		printf("p1 和 p3 指向相同的内存地址\n");
	}
	
	return 0;
}
```
编译并执行
```bash
p1 和 p2 指向相同的内存地址
p1 和 p3 指向不同的内存地址
```

**大小比较**
```c
#include <stdio.h>

int main()
{
	int arr[] = {10, 20, 30, 40, 50};
	int *p1 = &arr[1]; // 指向arr[1], 值为20	
	int *p2 = &arr[3]; // 指向arr[3], 值为40
	
	if (p1 < p2)
	{
		printf("p1 在 p2 之前\n");
	}
	else
	{
		printf("p1 在 p2 之后或相同位置\n");
	}
	
	if (p1 > p2)
	{
		printf("p1 在 p2 之后\n");
	}
	else
	{
		printf("p1 在 p2 之前或相同位置\n");
	}
	
	return 0;
}
```
编译并执行
```bash
p1 在 p2 之前
p1 在 p2 之前或相同位置
```

**遍历数组比较**
```c
#include <stdio.h>

int main()
{
	int arr[] = {10, 20, 30, 40, 50};
	int *start = arr; // 指向数组的第一个元素arr[0], 值为10	
	int *end = &arr[4]; // 指向数组的最后一个元素arr[4], 值为50
	int *p;
	
	for(p = start; p <= end; p++)
	{
		printf("当前指针指向的值: %d\n", *p);
	}
	
	return 0;
}
```
编译并执行
```bash
当前指针指向的值: 10
当前指针指向的值: 20
当前指针指向的值: 30
当前指针指向的值: 40
当前指针指向的值: 50
```

- 相等比较 (== 和 !=): 用于判断两个指针是否指向相同的内存位置。
- 大小比较 (<, >, <=, >=): 通常用于指针遍历数组或内存块时，判断一个指针是否在另一个指针之前或之后。
