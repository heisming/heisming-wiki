# 指针和函数的关系

## 函数指针（指向函数的指针）
一个函数在编译之后，会占据一部分内存，而它的函数名，就是这段函数的首地址。

C 语言规定函数名会被转换为指向这个函数的指针，除非这个函数名作为 & 操作符或 sizeof 操作符的操作数(注意：函数名用于 sizeof 的操作数是非法的)。

也就是说 `f = test;` 中 test 被自动转换为 &test，而 `f = &test;` 中已经显示使用了 &test，所以 test 就不会再发生转换了。因此直接引用函数名等效于在函数名上应用 & 运算符，两种方法都会得到指向该函数的指针。

指向函数的指针必须初始化，或者具有值，才能在函数调用中使用。

与数组一样：
- 禁止对指向函数的指针进行自增运算++
- 禁止对函数名赋值，函数名也不能用于进行算术运算。

```c
#include <stdio.h>

int add(int a, int b)
{
	return a + b;
}

int main(void)
{
	int (*p)(int, int); // 函数指针
	p = add;// 这里&add和add的值和类型都一样
	int ret = (*p)(5, 7); // 通过函数指针调用函数。
	printf("add = %d\n", ret);
	
   	return 0;
}
```
